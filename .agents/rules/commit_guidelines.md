# Commit Message Rules for OmniShift

- Every commit message must contain strictly between 4 and 6 words.
- No conventional commit prefixes (no `feat`, `fix`, `chore`, `refactor`, etc.).
- No parentheses, brackets, colons, or trailing punctuation marks (e.g. no dots at the end).
- Format: Plain text descriptive words only (e.g. `initialize omnishift in memory platform`).
